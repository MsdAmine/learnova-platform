# Learnova Landing Page Structure

## 1. Navbar

* Logo
* Navigation links
* Login button
* CTA button

---

## 2. Hero Section

Purpose:

* Explain the value proposition immediately

Contains:

* Headline
* Supporting text
* Primary CTA
* Secondary CTA
* Hero image

---

## 3. Feature Highlights

Purpose:

* Present core platform capabilities

Contains:

* Course discovery
* Live sessions
* Certifications
* Learning paths

---

## 4. Learning Journey Sections

Purpose:

* Explain the user flow step-by-step

Flow:

1. Discover courses
2. Enroll and learn
3. Earn certificates

---

## 5. Statistics Section

Purpose:

* Build trust and credibility

Metrics:

* Active learners
* Courses
* Certificates

---

## 6. Testimonials

Purpose:

* Social proof

Contains:

* Learner stories
* Company/instructor references

---

## 7. Final CTA

Purpose:

* Encourage signup

Contains:

* Motivational headline
* CTA buttons
* Supporting image

---

## 8. Footer

Contains:

* Navigation groups
* Legal links
* Social links
* Copyright
