# Learnova Brand Guidelines

# Brand Direction

Learnova is a modern learning platform focused on:

* Skill growth
* Structured learning
* Productivity
* Professional development

The platform should feel:

* Calm
* Clean
* Motivating
* Intelligent
* Modern

Avoid:

* Generic LMS aesthetics
* Corporate enterprise design
* Excessive gamification visuals
* Overdesigned interfaces

---

# Visual Style

The interface should resemble:

* Linear
* Notion
* Arc Browser
* Stripe Dashboard
* Modern productivity SaaS

---

# UI Principles

## Layout

* Spacious layouts
* Large readable sections
* Clear visual hierarchy
* Soft rounded corners

## Components

* Minimal shadows
* Clean borders
* Subtle hover effects
* Consistent spacing

## Cards

* Light surfaces
* Clear separation
* Minimal clutter

---

# Dashboard Direction

Dashboards should:

* Prioritize progress tracking
* Emphasize learning continuity
* Surface actionable information
* Reduce cognitive overload

---

# Branding Rules

## Logo

* Use script wordmark on marketing pages
* Use icon variant for sidebar/app/favicon

## Colors

* Salem is the dominant action color
* Use Coral and Anzac sparingly
* Large surfaces should stay neutral

## Typography

* Inter is the primary UI font
* Script typography is branding-only

---

# Motion & Interaction

Animations should be:

* Subtle
* Smooth
* Functional
* Non-distracting

Avoid:

* Flashy transitions
* Heavy parallax
* Aggressive motion

---

# Tone of Voice

Use:

* Clear educational language
* Friendly professionalism
* Motivational but concise messaging

Avoid:

* Buzzwords
* Overly academic tone
* Corporate jargon
