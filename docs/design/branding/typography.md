# Learnova Typography System

# Primary Typeface

## Inter

* Source: Google Fonts
* Usage:

  * Entire UI system
  * Dashboard layouts
  * Forms
  * Navigation
  * Cards
  * Tables

Reason:
Inter provides excellent readability for productivity-focused interfaces and modern SaaS dashboards.

---

# Logo Typography

## Learnova Wordmark

* Custom handwritten script
* Used only for branding/logo
* Never used for interface text

---

# Heading Scale

## H1

* Size: 56px
* Weight: 700
* Line Height: 1.1
* Usage: Hero sections

## H2

* Size: 40px
* Weight: 700
* Usage: Section headers

## H3

* Size: 28px
* Weight: 600
* Usage: Dashboard titles

## H4

* Size: 22px
* Weight: 600

# Button Typography

## Primary Buttons

# Design Rules

* Use whitespace generously
* Avoid heavy font weights
* Use sentence case
* Keep interfaces readable and calm
* Prioritize clarity over decoration
